# PinCheck 📍

A gamified travel tracking app and social passport designed to map adventures, collect stamps, and share verified destination statistics.

---

## 🌟 Key Features

- **Multi-Tier Classification:** Mutually exclusive tracking across **Countries**, **Cities**, and **Islands**.
- **Passport Star Progression:** 5-tier dynamic rank ladder (Explorer to World Legend) balancing global travel breadth with local depth.
- **Activity Pinning:** 4 core travel categories (**Sights 🏛️**, **Food 🍽️**, **Cafes ☕**, and **Drinks 🍺**) with local beer tracking.
- **Social Sharing:** Dedicated native text + link sharing for web passport profiles (`pincheck.app/@username`).
- **Cloud Architecture:** Designed for real-time sync and zero-cost scaling with Supabase (PostgreSQL) and Expo/React Native.

---

## 🛠️ Tech Stack

- **Framework:** React Native / Expo (`App.js`, `eas.json`)
- **Language:** JavaScript (ESNext)
- **Tooling:** ESLint, Expo Application Services (EAS)
- **Database & Auth:** Supabase (PostgreSQL)

---

## 🚀 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/annachris3/pincheck.git
   cd pincheck
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the Expo development server:**
   ```bash
   npx expo start
   ```
